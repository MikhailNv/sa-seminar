# Семинары предмета "Архитектура приложений и систем"

Этот проект содержит задания для семинаров по предмету "Архитектура приложений и систем"

## Структура веток

- **`seminar_1`** — **Первый семинар** 
  Содержит всю информацию первого семинара.

- **`seminar_2`** — **Второй семинар** 
  Содержит всю информацию второго семинара.

- **`seminar_3`** — **Третий семинар**
  Содержит задания третьего семинара. Задание 1 — документирование архитектуры SuperSurance в нотации C4: контекст, контейнеры, компоненты и код.

## Семинар 3 — задание 1

- [`задание_1_C4.md`](задание_1_C4.md) — описание архитектуры, границы, легенда, таблицы элементов и связей, трассировка требований.
- `задание_1_C4_уровень_1_контекст.drawio` — C4 Level 1.
- `задание_1_C4_уровень_2_контейнеры.drawio` — C4 Level 2.
- `задание_1_C4_уровень_3_компоненты_proposal.drawio` — C4 Level 3, Proposal Service.
- `задание_1_C4_уровень_3_компоненты_integration.drawio` — C4 Level 3, Integration Service.
- `задание_1_C4_уровень_4_erd_proposal.drawio` — C4 Level 4, ERD Proposal DB.

В текущий комплект входят Level 1, Level 2, две компонентные диаграммы Level 3 и одна диаграмма кода Level 4 (ERD). Диаграммы уровней 1–3 выполнены на встроенной библиотеке C4 draw.io (`More Shapes → C4`), ERD — в стандартной ERD-нотации. Все файлы открываются в [draw.io](https://app.diagrams.net) или desktop-приложении draw.io.
